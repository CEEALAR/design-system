# CEEALAR Website — UI kit

A hi-fi recreation of the CEEALAR marketing website, built from the brand book patterns. Single-page composition that demonstrates header, hero, stats, "what we offer," quote, alumni, apply CTA, footer.

No production CEEALAR.org code was read for this kit; pieces are extrapolated from the brand book + rollup banner. Treat as the canonical visual reference for new marketing pages until the live site is imported.

## Components
- `Header.jsx` — sticky top nav with logo lockup + apply button
- `Hero.jsx` — teal feature block with eyebrow + sans/serif headline + body + CTAs
- `StatBlock.jsx` — three stat cards in a row
- `OfferList.jsx` — two-column "what we offer" bullet list with closing flourish
- `QuoteBlock.jsx` — resident testimonial on teal
- `AlumniRoll.jsx` — pill grid of alumni institutions
- `ApplyCTA.jsx` — full-bleed cream block ending in primary button
- `Footer.jsx` — ink-900 footer with logo + meta

## Run
Open `index.html` — it stitches every component together into the marketing-page top-to-bottom.
